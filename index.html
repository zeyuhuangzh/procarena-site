ProcArena

A Lifecycle-Oriented Interactive Benchmark for NL-to-PL/SQL

Real database development is not one prompt and one answer. ProcArena spans the whole PL/SQL lifecycle — synthesis, evolution, transformation — and plays every task in two modes: single-turn, with the full specification up front, and multi-turn, where the model must interrogate a simulated user and the live database to earn the specification back. One criterion throughout: execution-state equivalence (EX). Every cell below opens the full trace of a real episode.
